# Contributing Guidelines

Thank you for considering contributing to the Awesome Living in Germany list! This document outlines the process and guidelines for contributing.

## How to Contribute

1. **Fork the repository** to your own GitHub account
2. **Clone your fork** to your local machine
3. **Create a new branch** for your contribution
4. **Make your changes** following the guidelines below
5. **Commit your changes** with clear, descriptive commit messages
6. **Push to your fork** on GitHub
7. **Submit a pull request** to the main repository

## Contribution Guidelines

### General Rules

- **Quality over quantity** - Only suggest resources that you have personally used or that are widely recognized as valuable
- **One suggestion per pull request** - This makes it easier to review and discuss
- **Search before suggesting** - Check if your suggestion already exists in the list
- **Check your spelling and grammar** - Ensure all text is clear and error-free
- **Use proper formatting** - Follow the existing style and structure

### Adding Resources

When adding a new resource, please ensure:

1. **It's relevant** - The resource should be directly related to living in Germany
2. **It's accessible** - Prefer resources that are free or have free tiers
3. **It's current** - Links should be active and content should be up-to-date
4. **It's legal** - Only suggest legal and legitimate resources
5. **It's in English or German** - Or both, with clear indication of language

### Format

Use this format for adding items:

```markdown
- [Resource Name](https://url.com) - Brief description of what it offers
```

For sections with subsections, maintain the existing hierarchy.

### What to Include

Good additions include:
- Official government resources
- Well-established services and platforms
- Comprehensive guides and documentation
- Active communities and forums
- Useful apps and tools
- Educational resources

### What NOT to Include

Please avoid:
- Broken or dead links
- Paid services without significant free offerings
- Overly commercial or promotional content
- Duplicate resources already listed
- Resources in languages other than English or German
- Illegal or questionable services
- Personal blogs (unless exceptionally authoritative)

## Updating Existing Content

If you notice:
- **Broken links** - Please update or remove them
- **Outdated information** - Update with current information
- **Better alternatives** - Suggest replacements with justification
- **Typos or errors** - Fix them!

## New Categories

If you want to suggest a new category:
1. Ensure it has enough quality resources (at least 5-7 items)
2. Verify it doesn't fit into existing categories
3. Provide a clear description of what the category covers
4. Place it logically within the table of contents

## Code of Conduct

By participating in this project, you agree to:
- Be respectful and constructive
- Welcome newcomers and help them learn
- Focus on what is best for the community
- Show empathy towards other community members

## Questions?

If you have questions about contributing, feel free to:
- Open an issue for discussion
- Ask in your pull request
- Check existing issues and pull requests for similar discussions

## Recognition

All contributors will be recognized for their contributions. Thank you for helping make this resource better for everyone!
